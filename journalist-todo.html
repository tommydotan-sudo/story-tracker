Welcome to Story Tracker

Your data syncs via a private GitHub Gist — free and nothing to install. You just need a GitHub Personal Access Token.

Setup steps:
1. Go to github.com → Settings → Developer settings → Personal access tokens → Tokens (classic)
2. Click Generate new token (classic)
3. Give it any name, tick the gist checkbox, click Generate
4. Paste the token below

Starts with ghp_. Keep it secret — it's your key to the data.

Data stays in this browser only — nothing is saved to the cloud.
