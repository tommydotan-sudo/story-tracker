To sync your data across devices, you'll need a free Supabase account. This only takes ~2 minutes to set up once.

Setup steps:
1. Go to supabase.com → New project
2. In the SQL editor, run the SQL shown below
3. Go to Project Settings → API and paste your URL + anon key here

Use the same passphrase on every device.

Show required SQL to run in Supabase 
create table if not exists tracker_data (
  id text primary key,
  data jsonb not null default '[]',
  updated_at timestamptz default now()
);

-- Allow public read/write (data is protected by your passphrase key)
alter table tracker_data enable row level security;
create policy "anon all" on tracker_data for all to anon using (true) with check (true);
